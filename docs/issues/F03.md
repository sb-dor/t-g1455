# A resting GlassSwitch registers a captured glass surface, though the docs say it is ordinary paint

## Summary

The switch page says:

> At rest the knob and the track are ordinary paint, not glass. The drop exists only while the switch is held, so a page with twenty switches costs the glass nothing until someone touches one.
> — https://g1455.plugfox.dev/components/switch

With twenty switches at rest, the glass ledger reports **20 surfaces, 20 captured**. `debugPaintGlassSurfaces`, which "outlines every registered surface", outlines every resting knob.

## Environment

- g1455 0.2.0, Flutter 3.47.1 stable
- iPhone 17 Pro simulator, iOS 26.5, Impeller (Metal), debug build

## Steps to reproduce

1. Put 20 `GlassSwitch`es in a grid under a `GlassHost`, and don't touch them.
2. Read the ledger once a second:
   `GlassScope.maybeOf(context)?.read(viewSize: MediaQuery.sizeOf(context), model: GlassHardware.detect().surfaceCostModel)`.
3. Optionally set `debugPaintGlassSurfaces = true`.

## Expected behaviour

`0 surfaces, 0 captured` while no switch is held, as the docs describe, and no outlines on resting knobs.

## Actual behaviour

| Switches at rest | `surfaceCount` | `capturedSurfaceCount` | `screensOfGlass` |
|---|---|---|---|
| 20 | 20 | 20 | 0.052 |
| 0 | 0 | 0 | 0.000 |

Every resting knob is outlined in cyan.

## Minimal code

```dart
GridView.count(
  crossAxisCount: 4,
  children: <Widget>[
    for (int i = 0; i < 20; i++)
      Center(child: GlassSwitch(value: i.isEven, onChanged: (_) {})),
  ],
)
// under MaterialApp(builder: (c, child) => GlassHost(child: child!))
```

The full app, with the ledger readout and a `SWITCHES` / `OUTLINES` dart-define, is in [repro/f03_switch_at_rest_surfaces.dart].

## Question

Either the resting knob is registered (and counted as captured) when it shouldn't be, or the ledger counts surfaces that draw and cost nothing. In that second case `capturedSurfaceCount` and the docs' cost claim are misleading for anyone budgeting with the ledger.
