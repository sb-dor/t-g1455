# The `GlassBackdropReading` dartdoc example picks white icons on light glass, against the caveat on its own `brightness` getter

## Summary

The class-level example on `GlassBackdropReading` (`glass_adaptive.dart`, lines 200-205) maps `brightness` to an icon colour:

```dart
/// final GlassBackdropReading? reading = GlassTheme.of(context).reading;
/// final Color icon = reading?.brightness == Brightness.light
///     ? const Color(0xFF000000)
///     : const Color(0xFFFFFFFF);
```

The getter it uses says it is not the branch the glass is drawn on (lines 228-233):

```dart
  /// Whether the backdrop is light or dark, by which of black and white stands
  /// out more against it — the label rule ([GlassFinish.foregroundOver]) with
  /// no glass between.
  ///
  /// Not the branch of `.regular`, which depends on the appearance as well;
  /// `GlassTheme.of(context).finish` is that.
```

The site's "Content on the glass" snippet (https://g1455.plugfox.dev/foundations/adaptive) computes the same `overLight` line (`reading?.brightness == Brightness.light`) and stops there; the site's API table also says `brightness` is "Not the branch of the glass." So the class-level example contradicts the caveat on its own getter, and anyone who copies the example over the glass gets the wrong colour: the branch comes from a different test. `GlassFinish.regular` compares the backdrop level with the appearance's threshold (`kRegularSwitchLight` 54 in the light appearance, `kRegularSwitchDark` 222 in the dark one; `glass_finish.dart` lines 368, 374, 401-403), while `brightness` is where black and white contrast equally against the mean, at a level of about 118 (relative luminance 0.179, encoded).

The two disagree for backdrops between 54 and about 118 in the light appearance: the glass is `regularLight` and `reading.brightness` is `dark`, so the example paints a **white icon on light glass**. In the dark appearance the range is about 118 to 222: `brightness` is `light` while the glass is still `regularDark`, so the example paints a black icon on dark glass.

## Environment

- g1455 0.2.0, Flutter 3.47.1 stable
- iPhone 17 Pro simulator, iOS 26.5, light system appearance, Impeller (Metal)

## Steps to reproduce

1. Use `GlassHost(adaptive: const GlassAdaptive(), backdrop: Color(0xFF464646))` over a flat grey page of luma 70.
2. Add a `GlassBar` with three marks: its own `Text` label, an icon coloured by the dartdoc example, and an icon coloured by `GlassTheme.of(context).legibility().label`.

## Expected behaviour

The example gives an icon colour that reads on the glass, as the bar's own label does.

## Actual behaviour

- The reading is `level 70.0`, `brightness: dark`.
- The finish is `regularLight`.
- The label from `legibility()` is black.
- The example gives **white**, which has low contrast on the light glass.

## Minimal code

```dart
class Marks extends StatelessWidget {
  const Marks({super.key});

  @override
  Widget build(BuildContext context) {
    final GlassThemeData theme = GlassTheme.of(context);
    final bool overLight = theme.reading?.brightness == Brightness.light; // the site's snippet
    return Row(children: <Widget>[
      const Text('Label'),
      const Spacer(),
      // the dartdoc example's mapping:
      Icon(Icons.star, color: overLight ? Colors.black : Colors.white),
      // what the bar uses:
      Icon(Icons.star, color: theme.legibility().label),
    ]);
  }
}
// GlassBar(child: Marks()) over a page of Color(0xFF464646), adaptive on, light appearance.
```

// F02: in the light appearance, adaptive glass over a backdrop between luma 54
// (GlassFinish.kRegularSwitchLight) and the black/white contrast midpoint
// (~118) is drawn on regularLight, while GlassBackdropReading.brightness says
// Brightness.dark. The GlassBackdropReading dartdoc example
// (glass_adaptive.dart:201-205) maps `reading?.brightness == Brightness.light`
// to a black icon and anything else to a white one, so it picks a white icon
// for light glass. The "Content on the glass" snippet on foundations/adaptive
// computes the same `overLight` and stops there.
//
// Run on a device or simulator in the LIGHT system appearance:
//   flutter run -t repro/f02_reading_brightness_recipe.dart
//   flutter run -t repro/f02_reading_brightness_recipe.dart --dart-define=LEVEL=40
//
// The page is one flat grey of luma LEVEL (default 70). The bar shows three
// marks: the bar's own label, an icon coloured by that example, and an
// icon coloured by GlassTheme.of(context).legibility().label.
import 'package:flutter/material.dart';
import 'package:g1455/g1455.dart';

const int kLevel = int.fromEnvironment('LEVEL', defaultValue: 70);

Color get _page => Color.fromARGB(255, kLevel, kLevel, kLevel);

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await GlassHost.precache();
  runApp(const ReproApp());
}

class ReproApp extends StatelessWidget {
  const ReproApp({super.key});

  @override
  Widget build(BuildContext context) => MaterialApp(
    debugShowCheckedModeBanner: false,
    builder: (BuildContext context, Widget? child) => GlassHost(
      backdrop: _page,
      adaptive: const GlassAdaptive(),
      child: child!,
    ),
    home: const Material(color: Color(0x00000000), child: ReproPage()),
  );
}

class ReproPage extends StatelessWidget {
  const ReproPage({super.key});

  @override
  Widget build(BuildContext context) => ColoredBox(
    color: _page,
    child: Stack(
      fit: StackFit.expand,
      children: <Widget>[
        // A caption for screenshots, in white at 60% so it shows on the grey
        // page. It is not under the bar: the bar's reading is the flat page
        // colour behind it.
        Center(
          child: Text(
            'page luma $kLevel · system appearance '
            '${MediaQuery.platformBrightnessOf(context).name}',
            style: TextStyle(color: Colors.white.withValues(alpha: 0.6)),
          ),
        ),
        Positioned(
          left: 16,
          right: 16,
          top: MediaQuery.paddingOf(context).top + 16,
          child: const GlassBar(child: _Marks()),
        ),
      ],
    ),
  );
}

class _Marks extends StatelessWidget {
  const _Marks();

  @override
  Widget build(BuildContext context) {
    final GlassThemeData theme = GlassTheme.of(context);
    final GlassBackdropReading? reading = theme.reading;
    // `overLight` is the line from foundations/adaptive, "Content on the
    // glass"; mapping it to black/white is the dartdoc example on
    // GlassBackdropReading (glass_adaptive.dart:201-205).
    final bool overLight = reading?.brightness == Brightness.light;
    final Color recipe = overLight ? const Color(0xFF000000) : const Color(0xFFFFFFFF);
    final Color label = theme.legibility().label;
    debugPrint(
      'F02 level ${reading?.level.toStringAsFixed(1)}'
      ' reading.brightness ${reading?.brightness.name}'
      ' finish ${theme.finish.name}'
      ' label $label recipe $recipe'
      ' appearance ${MediaQuery.platformBrightnessOf(context).name}',
    );
    return Row(
      children: <Widget>[
        const Text('Label'),
        const Spacer(),
        Icon(Icons.star, color: recipe),
        const SizedBox(width: 4),
        const Text('recipe'),
        const SizedBox(width: 16),
        Icon(Icons.star, color: label),
        const SizedBox(width: 4),
        const Text('legibility()'),
      ],
    );
  }
}

## Suggestion

Point the example at the label (or the branch) instead of `brightness`:

```dart
final Color onGlass = GlassTheme.of(context).legibility().label;
```
