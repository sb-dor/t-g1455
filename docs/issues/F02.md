# Adaptive "Content on the glass" recipe picks white icons on light glass (`reading.brightness` ≠ the branch drawn)

## Summary

The adaptive guide gives this recipe for an icon or a painter on adaptive glass:

```dart
final GlassBackdropReading? reading = GlassTheme.of(context).reading;
final bool overLight = reading?.brightness == Brightness.light;
```

`GlassBackdropReading.brightness` says whether black or white contrasts more with the *backdrop's mean*. The branch the glass is drawn on comes from a different test: `GlassFinish.regular` compares the level with the appearance's threshold (`kRegularSwitchLight` 54 in the light appearance, `kRegularSwitchDark` 222 in the dark one).

The two disagree for backdrops between about 54 and 118 in the light appearance, and in the mirror range in the dark one. There the glass is `regularLight` and `reading.brightness` is `dark`, so the recipe paints a **white icon on light glass**.

## Environment

- g1455 0.2.0, Flutter 3.47.1 stable
- iPhone 17 Pro simulator, iOS 26.5, light system appearance, Impeller (Metal)

## Steps to reproduce

1. Use `GlassHost(adaptive: const GlassAdaptive(), backdrop: Color(0xFF464646))` over a flat grey page of luma 70.
2. Add a `GlassBar` with three marks: its own `Text` label, an icon coloured by the documented recipe, and an icon coloured by `GlassTheme.of(context).legibility().label`.

## Expected behaviour

The documented recipe gives an icon that reads on the glass, as the bar's own label does.

## Actual behaviour

- The reading is `level 70.0`, `brightness: dark`.
- The finish is `regularLight`.
- The label from `legibility()` is black.
- The recipe gives **white**, which is barely visible on the light glass.

## Minimal code

```dart
class Marks extends StatelessWidget {
  const Marks({super.key});

  @override
  Widget build(BuildContext context) {
    final GlassThemeData theme = GlassTheme.of(context);
    final bool overLight = theme.reading?.brightness == Brightness.light; // the docs' recipe
    return Row(children: <Widget>[
      const Text('Label'),
      const Spacer(),
      Icon(Icons.star, color: overLight ? Colors.black : Colors.white), // recipe
      Icon(Icons.star, color: theme.legibility().label),                // what the bar uses
    ]);
  }
}
// GlassBar(child: Marks()) over a page of Color(0xFF464646), adaptive on, light appearance.
```

The full app is in [repro/f02_reading_brightness_recipe.dart] (`--dart-define=LEVEL=<0..255>` to move the page).

## Suggestion

Point the recipe at the branch or the label instead:

```dart
final Color onGlass = GlassTheme.of(context).legibility().label;
```

Alternatively, add something like `reading.branch(appearance)`. If `brightness` is meant to describe the backdrop, say so next to it.
